# Zdroje a hranice dôkazov pre `01_bayes_online`

Tento experiment je **vlastná adaptácia**. Nižšie uvedené publikácie neurčujú parametre Gemini Lab a nepredstavujú výsledky tohto programu. Nové fyzické údaje vzniknú až spustením Windows alebo Mac launchera a sú platné iba v rozsahu doloženom uloženými FID, odoslanými povelmi a nezávislými kontrolami. Verzia skúšaného klienta je SpinQLabLink **1.0.2**; správanie tabletu a časovej osi musí potvrdiť živé meranie.

## Dôkazová hierarchia

1. **Numerická kontrola** overuje algebru, serializáciu a offline invarianty. Nie je meraním Gemini Lab.
2. **Pilotný FID** môže potvrdiť úplnosť exportu, časovú os a informatívne jednorozmerné pulzové odozvy. Parametre z pilotu sú platený nominálny anchor, nie skrytá pravda.
3. **Kvalifikácia primitívu** vyžaduje samostatné fyzické kontrolné merania časovania, H/P spoločnej osi, J znamienka a čítacieho modelu. Bez nich musí nadväzná PPS/Bell úloha skončiť konkrétnym `UNSUPPORTED_REQUIRED_PRIMITIVE` alebo `NONIDENTIFIABLE`.
4. **Tvrdenie o výhode** vyžaduje rovnaké rozladenie, vlastné tréningové údaje každej metódy, zmrazený evaluator, nezávislé kontroly a porovnanie fyzických akvizícií aj celkového času po blokoch. Úspešný fit alebo ideálna numerická Bellova matica nestačí.
